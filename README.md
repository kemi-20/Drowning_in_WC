# 去王超 (Drowning in WC)

> **"当校园梦魇化作高维深渊，精神控制在绝对资本面前被彻底碾碎。"**

##  作品简介

《去王超》（英文名：*Drowning in WC*）是一部探讨阶级降维打击、病态心理异化与青春期梦魇的暗黑向开源文学项目。

故事发生在一个能将潜意识阴影具象化的扭曲空间——**“王超”（WC）**。自诩为精神掌控者的穷困男高中生 **P**，在这里遭遇了拥有绝对资本与暴力的上位者 **H**。在五千万债务的现实重压下，P 眼睁睁看着自己深爱的女孩 **T**，从恐惧、挣扎到最终在绝对的安全感中彻底沦陷。

这是一场关于肉体剥夺、灵魂规训与尊严凌迟的心理学剖析。在这个充斥着“解析几何孔雀”与“催命鹦鹉”的荒诞动物园里，我们一起溺毙。

##  核心设定
- **坏壤 (Bad Soil)**：无限放大潜意识阴影的灰黑色土壤。
- **神秘动物园**：校园梦魇的变异场所（汤加孔雀、凯云象、天怡鹅等）。
- **MKK (猴王)**：高维神明，以绝望与扭曲欲望为食的绝对主宰。
- **SM共存体**：主角 P 在极致压抑下的心理异化状态。

##  参与共创
本项目采用开源共创模式，欢迎通过以下方式贡献：
1. **词句润色**：修正错别字，优化极致压抑的文学表达。
2. **世界观扩展**：为“王超”设计更多带有社会/校园隐喻的怪物设定。
3. **衍生二创**：欢迎基于本项目创作插画、漫画、视觉小说脚本等。
