# 去王超 (Drowning in WC)

> **"如果我的存在是你奔向光明的最后一道枷锁，那么死亡，是我能给你的最极致的温柔。"**

##  作品简介

《去王超》（英文名：*Drowning in WC*）是一部探讨阶级降维打击、病态心理异化与青春期梦魇的暗黑向开源文学项目。

故事发生在一个能将潜意识阴影具象化的扭曲空间——**“王超”（WC）**。自诩为精神掌控者的穷困男高中生 **P**，在这里遭遇了拥有绝对资本与暴力的上位者 **H**。在五千万债务的现实重压下，P 眼睁睁看着自己深爱的女孩 **T**，从恐惧、挣扎到最终在绝对的安全感中彻底沦陷。

这是一场关于肉体剥夺、灵魂规训与尊严凌迟的心理学剖析，更是一场以爱为名、双向误解的残忍献祭。在这个充斥着荒诞怪物的深渊里，我们一起溺毙。

##  参与共创
本项目采用开源共创模式，欢迎通过以下方式贡献：
1. **词句润色**：优化极致压抑的文学表达。
2. **世界观扩展**：为“王超”设计更多带有社会/校园隐喻的怪物设定。
3. **衍生二创**：欢迎基于本项目创作同人文、插画、漫画、视觉小说脚本等。
